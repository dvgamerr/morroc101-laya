### A1. Damage tracker ไม่เคยได้ sample — [x2]
- **ที่:** `src/main.js:1031`, `src/main.js:483`, `src/potions.js:157`
- **ปัญหา:** `damage.sample()` ถูกเรียกจาก `checkOutpaced()` (main.js:1051) เท่านั้น และเก็บค่าเฉพาะเมื่อ `snap.attackers.length > 0` แต่ทุก tick ที่มี attacker จะเข้า fight branch ที่ main.js:1031 แล้ว `continue` ก่อน → `damage.p90()` เป็น null ตลอด
- **ผล:**
  - หลังอยู่แมพ 3 นาที dps = 0 → `carried >= need` จริงเสมอ, potion upgrade (532) และออกจากแมพเพราะยาไม่ทัน (543-550) ไม่เคยทำงาน
  - `tooEasy` จริงทุก 5 นาที → `levelOffset` ขยับขึ้นเอง + เรียก `chooseHunt` บนข้อมูลผิด
  - errand `getDps()` ได้ null เสมอ (errand.js:217, 328, 516)
  - `hardMaps` บันทึก `dps: 0`
- **ต้นเหตุ:** commit ee81beb
